# Cloud Computing Fundamentals

**Domain:** Cloud & Cybersecurity  
**Level:** Beginner

Understand cloud service models, deployment, access control, and cost awareness.

## Module 1: Cloud Concepts

### What is cloud computing?

Cloud computing provides on-demand access to computing resources over a network. Capacity can often be provisioned and released without buying physical servers.

### Service models

IaaS provides configurable infrastructure, PaaS provides a managed application platform, and SaaS provides a finished application to end users.

## Module 2: Security Basics

### Identity and access management

Grant each identity only the permissions required for its task. Use multifactor authentication where available and remove access when it is no longer needed.

### Shared responsibility

Cloud providers secure parts of the underlying service, while customers remain responsible for configured identities, data, applications, and other controls according to the service model.

## Module 3: Reliability and Cost

### Availability and backups

Use backups, recovery tests, monitoring, and suitable redundancy to reduce the impact of failures. A backup is useful only if restoration works.

### Cost management

Tag resources, set budgets and alerts, right-size instances, and shut down unused development resources. Understand data transfer and storage costs.
