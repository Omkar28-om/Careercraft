# Cybersecurity Fundamentals

**Domain:** Cloud & Cybersecurity  
**Level:** Beginner

Learn defensive security principles, phishing awareness, authentication, and incident response.

## Module 1: Security Principles

### Confidentiality, integrity, availability

Confidentiality limits unauthorised disclosure, integrity protects correctness, and availability ensures authorised users can access systems when needed.

### Threats and vulnerabilities

A threat may exploit a vulnerability to cause harm. Risk depends on likelihood and impact, and controls can reduce but rarely eliminate risk.

## Module 2: Safer Accounts and Devices

### Authentication

Use unique passwords stored in a reputable password manager and enable multifactor authentication. Never share one-time codes or recovery codes.

### Phishing awareness

Check the sender, domain, urgency, unexpected attachments, and requests for credentials or payments. Verify sensitive requests using a separate trusted channel.

## Module 3: Defensive Response

### Updates and backups

Apply security updates promptly, use supported software, restrict permissions, and maintain protected backups.

### Incident response

Report suspected incidents quickly, preserve relevant evidence, follow the organisation's response plan, and avoid making changes that destroy useful evidence.
