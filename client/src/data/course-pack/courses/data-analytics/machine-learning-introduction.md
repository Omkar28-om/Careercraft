# Introduction to Machine Learning

**Domain:** Data & Analytics  
**Level:** Beginner

An original overview of supervised learning, evaluation, and responsible model use.

## Module 1: Core Ideas

### What is machine learning?

Machine learning uses data to fit a model that makes predictions or identifies patterns. It is useful when rules are difficult to specify manually.

### Supervised and unsupervised learning

Supervised learning uses labelled examples. Unsupervised learning explores structure in data without a target label, such as grouping similar records.

## Module 2: Training and Evaluation

### Train, validation, and test sets

Training data fits model parameters. Validation data helps select settings. A held-out test set estimates performance on unseen examples.

### Classification metrics

Accuracy is the fraction of correct predictions. Precision measures how many predicted positives are true positives; recall measures how many actual positives were found.

## Module 3: Risks and Deployment

### Overfitting and leakage

Overfitting occurs when a model learns training-specific noise. Data leakage occurs when training uses information unavailable at prediction time.

### Responsible AI

Assess data representativeness, privacy, fairness, explainability, and the consequences of mistakes. Monitor models after deployment because data can change.
