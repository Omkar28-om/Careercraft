# Data Analytics Foundations

**Domain:** Data & Analytics  
**Level:** Beginner

Learn a simple workflow for turning raw data into useful decisions.

## Module 1: Asking Good Questions

### Analytics workflow

Start with a decision or question, define metrics, collect relevant data, validate quality, analyse patterns, and communicate findings with limitations.

### Data quality

Check missing values, duplicates, inconsistent units, invalid ranges, and outdated records before drawing conclusions.

## Module 2: Tables and SQL Concepts

### Rows, columns, and keys

A table stores records in rows and attributes in columns. A primary key uniquely identifies a row; a foreign key links related tables.

### Filtering and aggregation

SQL SELECT retrieves columns, WHERE filters rows, GROUP BY aggregates categories, and ORDER BY sorts the output.

## Module 3: Communicating Insights

### Choosing charts

Use bar charts for category comparisons, line charts for trends over time, and scatter plots for relationships between numeric variables.

### Responsible interpretation

Correlation alone does not establish causation. Explain the population, time period, assumptions, and uncertainty behind a result.
