# Web Development Foundations

**Domain:** IT & Software  
**Level:** Beginner

An original starter course introducing the core building blocks of websites.

## Module 1: How the Web Works

### Client, server, and HTTP

A browser is a client that requests resources from a server. HTTP defines how requests and responses are exchanged. A URL identifies a resource, while DNS helps translate domain names into IP addresses.

### Web page structure

HTML describes content and meaning. Semantic elements such as header, nav, main, article, and footer help browsers, assistive technologies, and search engines understand a page.

## Module 2: CSS and Responsive Layout

### CSS basics

CSS rules select elements and apply declarations such as color, spacing, borders, and typography. The box model consists of content, padding, border, and margin.

### Responsive design

Responsive layouts adapt to different screen sizes. Use flexible widths, CSS Grid or Flexbox, and media queries. Test keyboard navigation and readable text as well as visual layout.

## Module 3: JavaScript Fundamentals

### Variables and functions

Use const for values that are not reassigned and let for values that are. Functions package reusable logic and can accept parameters and return results.

### DOM and events

The Document Object Model represents a page as objects. JavaScript can select elements, update text, and respond to events such as clicks or form submissions.
