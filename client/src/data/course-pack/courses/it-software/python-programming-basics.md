# Python Programming Basics

**Domain:** IT & Software  
**Level:** Beginner

An original introduction to Python syntax, control flow, collections, and functions.

## Module 1: Getting Started

### Values and variables

Python variables refer to objects. Common built-in types include int, float, str, and bool. Use meaningful names and keep indentation consistent.

### Input and output

print() displays output and input() reads text from the user. Convert input explicitly with int() or float() when numeric calculations are required.

## Module 2: Logic and Collections

### Conditions and loops

if/elif/else chooses a path. for loops iterate over items, while loops repeat while a condition is true, and break exits a loop.

### Lists and dictionaries

Lists preserve order and allow indexed access. Dictionaries map unique keys to values and are useful for structured lookups.

## Module 3: Functions and Debugging

### Functions

Define reusable behaviour with def. Parameters receive inputs, return sends a result to the caller, and docstrings explain purpose and usage.

### Errors and testing

Read tracebacks from the bottom upward to find the immediate error. Test normal cases, boundary cases, and invalid inputs.
