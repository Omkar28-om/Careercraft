# Course pack attribution

CareerCraft includes course notes and multiple-choice questions adapted from the `Free_Course_Starter_Pack` supplied with this project. The supplied README identifies the material as original beginner-level content created for SkillForge and says it may be adapted, with attribution retained where practical. The pack contains 12 courses, 72 lesson notes, and 60 practice questions.

The supplied content is included as-is in `courses.json`, `questions.json`, and the Markdown files under `courses/`. The current domain labels are normalized in the frontend so the two Business course groups appear together as **Business, Management & Finance**.

Review the educational material and confirm attribution/licensing details with the original pack author before publishing CareerCraft outside this project.
